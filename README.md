# Knowledge Alchemy Pilot
児童向け図書探索支援システム Knowledge Alchemy のパイロットスタディ用UIプロトタイプ  
Pilot UI prototype for Knowledge Alchemy, a children's library discovery navigation system.

## 概要

本リポジトリは、修士プロジェクト（MP4）における予備的検証用のUIプロトタイプを管理するためのものです。

本プロジェクト「Knowledge Alchemy」は、児童が自分の興味や言葉を手がかりに図書を探索し、知識分野とのつながりを視覚的に理解できるようにする、児童向け図書探索支援システムです。

本リポジトリでは、パイロットスタディ段階の静的なUIデモを公開しています。

## 目的

本プロトタイプの目的は、以下の点を確認することです。

- 児童が操作しやすい画面構成になっているか
- 知識マップによって、興味と図書分野のつながりを直感的に理解できるか
- 対話型UIによって、児童が自分の興味を振り返りやすくなるか
- 今後のSBERTベクトル検索およびログ収集機能の実装に向けて、UI上の課題を整理すること

## 現在の実装範囲

現時点では、以下の機能を中心に実装しています。

- HTML / CSS / JavaScript による静的UI
- 児童向けの対話型画面
- 知識マップ表示
- 図書探索結果の提示画面
- パイロットスタディ用のダミーデータまたは小規模データの利用

なお、現段階では本格的なバックエンド処理やSBERTによるリアルタイム検索は未実装です。  
今後、Python / FastAPI / SBERT を用いたベクトル検索機能を段階的に統合する予定です。

## デモについて

このデモは、静的ホスティング上に配置したHTMLファイルをブラウザで実行するものです。

ホスティングサービス側でコード生成や自動実装は行っていません。  
本リポジトリ内のソースコードをもとに、ブラウザ上でUIプロトタイプを確認できるようにしています。

## 研究上の位置づけ

本システムは、児童が自分の言葉で図書探索を行い、検索結果や知識マップを通じて、自分の興味や関心分野を認識することを支援するものです。

最終的には、以下の観点から評価を行う予定です。

- 児童の自己認識の促進
- 探索行動の変化
- 知識分野への関心の広がり
- システム内ログと観察記録を用いた分析

## 今後の予定

- 修士論文本文への反映
